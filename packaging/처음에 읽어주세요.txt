1000+ 사이트의 영상/오디오를 최고화질로 받는 다운로더입니다.
(YouTube · TikTok · Instagram · 그 외 다수)

------------------------------------------------------------
■ 설치 방법 (Windows)
------------------------------------------------------------
1) Windows 폴더 안의 설치 파일을 실행하세요.
   - "Piggy Downloader Setup 1.0.0.exe"  → 설치형 (권장, 자동 업데이트 지원)
   - "PiggyDownloader-Portable-1.0.0.exe" → 무설치 (USB 등 휴대용)
2) "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러주세요.
   (코드 서명 전 단계라 표시되는 정상 안내입니다.)

■ 설치 방법 (macOS)
   macOS 폴더의 .dmg 를 열어 응용프로그램으로 드래그하세요.
   처음 실행 시 [제어판 > 개인정보 보호 및 보안]에서 [확인 없이 열기]를 눌러주세요.

------------------------------------------------------------
■ 사용 방법 (3초)
------------------------------------------------------------
1) 영상 주소(URL)를 복사하면 앱이 자동으로 인식합니다.
2) [불러오기] → [대기열 추가] 누르면 끝.
3) 파일은 무조건 [다운로드] 폴더에 저장됩니다.

   · 🎬 영상 = 무조건 최고화질로 받습니다.
   · 🎵 오디오 = MP3로 추출합니다.
   · 🤖 AI 자막 = 다운로드 후 음성을 분석해 자막(.srt)을 만듭니다.

------------------------------------------------------------
■ 크롬 확장 (브라우저 플로팅 버튼)  ─ 선택
------------------------------------------------------------
"chrome-extension.zip" 의 압축을 푼 뒤:
1) 크롬 주소창에  chrome://extensions  입력
2) 우측 상단 [개발자 모드] 켜기
3) [압축해제된 확장 프로그램을 로드] → 압축 푼 폴더 선택
→ 이제 어느 영상 페이지에서나 우측 하단 🐷 버튼으로 바로 다운로드!
  (앱이 실행 중이어야 합니다 / 우클릭하면 MP3 메뉴)

------------------------------------------------------------
■ 자동 업데이트
------------------------------------------------------------
설치형은 새 버전이 나오면 자동으로 업데이트됩니다.
(앱 실행 시 백그라운드로 확인 → 다운로드 → 다음 실행 때 적용)
