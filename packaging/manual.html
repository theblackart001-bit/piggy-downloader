Piggy Downloader

사용 매뉴얼 · v1.0.0

1. 프로그램 소개

Piggy Downloader는 YouTube · TikTok · Instagram 등 1000개 이상의 사이트에서 영상과 오디오를 받아주는 데스크톱 다운로더입니다. 강력한 yt-dlp 엔진과 ffmpeg, 그리고 AI 음성인식(Whisper)을 내장하여 별도 설치 없이 바로 사용할 수 있습니다.

기능설명
영상 다운로드무조건 최고화질로 받고 영상+오디오를 자동 병합(MP4)
오디오 추출MP3로 변환, 썸네일·메타데이터 포함
AI 자막다운로드 후 음성을 분석해 자막(.srt) 자동 생성 (무료·오프라인)
클립보드 감지주소를 복사하면 앱이 자동으로 인식
브라우저 버튼크롬 확장으로 어느 페이지에서나 플로팅 버튼 다운로드

2. 설치

Windows

  1. Windows 폴더의 Piggy Downloader Setup 1.0.0.exe(설치형, 권장) 실행
  2. "Windows의 PC 보호" 안내가 뜨면 [추가 정보] → [실행]
  3. 휴대용이 필요하면 PiggyDownloader-Portable-1.0.0.exe(무설치) 사용

macOS

  1. macOS 폴더의 .dmg를 열어 응용프로그램으로 드래그
  2. 첫 실행 차단 시 [개인정보 보호 및 보안] → [확인 없이 열기]

3. 기본 사용법

  1. 영상 페이지의 주소(URL)를 복사합니다 → 앱이 자동으로 감지해 채워줍니다.
  2. (수동) 주소창에 붙여넣고 [불러오기]를 누릅니다.
  3. 미리보기를 확인하고 [＋ 대기열 추가]를 누르면 다운로드가 시작됩니다.
  4. 완료된 파일은 무조건 [다운로드] 폴더에 저장됩니다. (상단 폴더 버튼으로 열기)
모드 전환 — 상단의 🎬 영상 / 🎵 오디오(MP3) 버튼으로 선택합니다. 영상은 항상 최고화질로 받습니다.

4. AI 자막 만들기

영상 모드에서 🤖 AI 자막을 체크하면, 다운로드가 끝난 뒤 음성을 분석해 같은 폴더에 .srt 자막 파일을 생성합니다. 한국어/영어 등 자동 인식하며 인터넷 없이 동작합니다.

처음 한 번은 음성인식 모델을 준비하느라 시간이 더 걸릴 수 있습니다. 더 정확한 자막이 필요하면 더 큰 모델로 교체할 수 있습니다(고급).

5. 크롬 확장 — 브라우저 플로팅 버튼

  1. chrome-extension.zip 압축 해제
  2. 크롬에서 chrome://extensions 접속 → 우측 상단 [개발자 모드] 켜기
  3. [압축해제된 확장 프로그램을 로드] → 압축 푼 폴더 선택
  4. Piggy Downloader 앱 실행 → 영상 페이지 우측 하단 🐷 버튼 클릭으로 즉시 다운로드
좌클릭 = 영상 / 우클릭 = 메뉴(영상·MP3) / 버튼을 위아래로 드래그하면 위치 이동. 앱과는 내 컴퓨터 안(127.0.0.1)에서만 통신하며 외부로 데이터를 보내지 않습니다.

6. 자동 업데이트

설치형은 새 버전이 나오면 앱 실행 중 자동으로 확인·다운로드하고, 다음 실행 때 적용됩니다. 하단 상태바에 "새 버전 준비됨"이 보이면 클릭해 즉시 재시작·적용할 수 있습니다.

7. 자주 묻는 질문
