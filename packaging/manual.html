유튜브 · 틱톡 · 인스타그램 등 1000개 이상의 사이트에서 영상과 음악을 받아주는 프로그램입니다.
필요한 건 전부 안에 들어 있어서, 따로 설치할 것이 없습니다.

1. 설치

🪟 Windows

  1. 압축을 풀고 설치 파일(.exe)을 더블클릭합니다.
  2. “Windows의 PC 보호” 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
  3. 설치가 끝나면 바탕화면에 🐷 아이콘이 생깁니다.

🍎 Mac

함께 들어 있는 「맥 사용자는 읽어주세요.txt」의 주소에서 Mac 용 파일을 받으세요.
내 Mac 이 어느 쪽인지는 → 이 Mac에 관하여에서 확인합니다.

  • “칩: Apple M1/M2/M3…” → arm64.dmg
  • “프로세서: Intel…” → x64.dmg

받은 .dmg 를 열고 🐷 아이콘을 응용 프로그램 폴더로 끌어다 놓으면 설치됩니다.

처음 실행할 때 경고가 뜹니다 — 정상입니다.
Windows 는 “PC 보호”, Mac 은 “확인되지 않은 개발자” 라고 나옵니다. 프로그램에 문제가 있어서가 아니라 아직 인증서를 붙이지 않아 뜨는 안내입니다.
· Windows: [추가 정보] → [실행]
· Mac: 아이콘을 오른쪽 버튼(또는 control+클릭) → [열기] → 경고창에서 다시 [열기]
처음 한 번만 하시면 됩니다.

2. 쓰는 법 — 주소만 복사하면 끝

영상 주소를 복사하면 바로 다운로드가 시작됩니다. 앱에서 따로 누를 것이 없습니다.

  1. 브라우저에서 영상 주소를 복사합니다.
  2. 끝입니다. 앱이 알아서 받습니다.

받은 파일은 [다운로드] 폴더에 저장됩니다. 앱 오른쪽 위 폴더 버튼을 누르면 그 폴더가 열립니다.

자동으로 안 받게 하려면 — ⚡ 복사하면 바로 받기 체크를 끄면 됩니다.
그러면 주소를 넣고 [불러오기]로 확인한 뒤 [⬇ 다운로드]를 눌러 받습니다.

여러 개를 한꺼번에 — 주소를 계속 복사하면 목록에 쌓이면서 동시에 받습니다. 하나가 끝날 때까지 기다리지 않아도 됩니다.

3. 알아두면 좋은 기능

버튼하는 일
📁 저장 위치 묻기 켜두면 받을 때마다 저장할 폴더를 물어봅니다.
꺼두면 항상 [다운로드] 폴더에 저장됩니다. (기본: 꺼짐)
✂️ 구간만 긴 영상에서 필요한 부분만 잘라서 받습니다.
체크하면 시작·끝 칸이 나옵니다. 0:30 처럼 적으면 됩니다.
끝을 비우면 끝까지, 시작을 비우면 처음부터 받습니다.
📜 받은 목록 지금까지 받은 것을 모아 봅니다.
폴더 열기로 파일 위치를 바로 열고, 다시 받기로 같은 주소를 한 번 더 받습니다.
🔑 로그인 인스타그램처럼 로그인해야 보이는 영상을 받을 때 씁니다. 아래 4번 참고.

4. 로그인해야 보이는 영상 받기

인스타그램·샤오홍슈 등은 로그인한 사람에게만 보이는 영상이 많습니다. 이런 영상은 그냥은 받아지지 않습니다. 앱의 [🔑 로그인] 버튼을 눌러 한 번만 연결해두면 그다음부터는 자동으로 됩니다.

🔒 비밀번호는 받지 않습니다. 로그인 상태를 나타내는 쿠키만 사용하며, 그 파일은 내 컴퓨터 안에만 저장되고 어디로도 전송되지 않습니다.
👤 되도록 부계정으로 로그인한 쿠키를 쓰시길 권합니다.

방법 1. 쿠키 파일 등록 (권장 · 가장 확실)

  1. 크롬에 확장 “Get cookies.txt LOCALLY” 를 설치합니다.
  2. 인스타그램 등에 로그인한 상태로 그 사이트를 엽니다.
  3. 확장 아이콘 클릭 → Export → cookies.txt 저장
  4. 앱에서 [🔑 로그인] → [📂 cookies.txt 파일 고르기] 로 그 파일을 고릅니다.

방법 2. 브라우저에서 바로 가져오기 (간편하지만 실패할 수 있음)

앱에서 Chrome / Edge / Whale / Firefox 중 하나를 누르면 됩니다. 다만 최신 크롬은 보안이 강화돼 실패할 수 있으니, 안 되면 방법 1을 쓰세요. 브라우저를 완전히 종료한 뒤 눌러야 잘 됩니다.

8. 자주 묻는 질문

Q. 다운로드가 안 됩니다.
인터넷 연결을 확인하고, 비공개·연령제한·삭제된 영상이 아닌지 확인해 주세요. 특정 사이트만 안 된다면 7번의 엔진 갱신을 해보시면 대부분 해결됩니다.

Q. 화질을 고르고 싶습니다.
항상 가장 좋은 화질로 받도록 만들어져 있어 선택하는 곳이 없습니다.

Q. 저장 위치를 바꾸고 싶습니다.
📁 저장 위치 묻기 를 체크하시면, 받을 때마다 저장할 폴더를 물어봅니다. 체크를 꺼두면 항상 [다운로드] 폴더에 저장됩니다.

Q. 여러 개를 한 번에 받을 수 있나요?
네. 주소를 계속 복사하시면 목록에 쌓이면서 동시에 받습니다.

Q. 인스타그램 영상이 안 받아집니다.
로그인해야 보이는 게시물일 수 있습니다. 위 4번을 참고해 한 번만 연결해 주세요.

Q. 받은 파일이 어디 있는지 모르겠습니다.
📜 받은 목록 을 누르고 [폴더 열기] 를 누르시면 그 파일 위치가 바로 열립니다.
